# MVT 注册、上树与 Cesium 显示设计

## 目标与验收

在已有中台注册 MVT 数据服务，将其加入当前场景图层树。大屏首页及地图管理中的图层树能够勾选显示、取消隐藏；刷新后资源和树节点仍在；反复切换不产生重复图层。用真实 Martin 瓦片及浏览器画面验证。

## 实证现状

- 中台服务类型已存在，code/zhname 为 MVT；不重复新增类型。
- 大屏共用 Cesium Viewer，LayerTreePop 提供 treeData、checkedKeys 状态；现有插件无 MVT 加载能力。
- Cesium.VectorTilesLayer 存在，但其依赖的全局 ol 未加载，不能直接假定支持标准 MVT。
- 本机 Martin 尚未运行。PostGIS jyxyd_dk_geom 有 1120 个 Polygon，列 geom 标为 4547。
- 按 4547 转换得到东经 113.745～114.837；按 4548 解释相同坐标得到东经 116.745～117.837、北纬 38.663～40.063，位于天津。

## 方案比较

1. 推荐：新增独立 Cesium ImageryProvider，解码标准 MVT 并逐瓦片绘制到透明 Canvas，继续用 Cesium 原有地图。按视野请求瓦片，不整批下载 GeoJSON。增加图层树宿主适配器，监听组件状态，按节点/资源 ID 控制图层。
2. 使用厂商 VectorTilesLayer：依赖旧版 OpenLayers 与特定服务协议，需补齐未知兼容层，风险较高。
3. 替换为 MapLibre 地图：原生支持 MVT 样式与交互，但会涉及现有三维地图、量测分析和页面交互的较大改动，超出当前目标。

## 推荐方案结构

- 数据：新增独立只读 PostGIS 视图，将原始坐标按 EPSG:4548 提供给 Martin。保留原表及原始几何。保存可重复执行的配置脚本及坐标核对查询。
- 服务：启动本机 Martin 3001，验证 TileJSON 范围、非空 MVT 和跨域响应。
- 中台：通过现有 UI/API 注册 MVT 资源，URL、范围等保存在资源配置，加入场景 682e495422944edb9054094ff7e771a9。
- 渲染：独立 MVT 加载器解码面/线/点，提供透明底、面填充与描边；使用 Cesium 影像瓦片调度和缓存。空瓦片按透明图处理；网络或解码失败显示明确提示并允许重试。
- 图层树：复用 LayerTreePop，不改闭源插件包、不全局拦截 XHR、不按名称匹配 DOM。适配器从 treeData 取 MVT 节点，监听 checkedKeys 和生命周期；同资源不重复创建；销毁时清理监听与资源。覆盖首页、地图管理和保留的旧地图入口。
- 定位：使用配置/TileJSON 的经纬度范围定位，避免整幅地球范围下肉眼不可见。

## 范围说明

服务传输与按需加载仍为 MVT；Canvas 在客户端将矢量瓦片绘为 Cesium 可用的透明影像。本次以地图显示和图层树显隐为验收，不扩展完整 Mapbox Style 规范或矢量要素编辑。原有业务 GeoJSON 的选中与详情链路保留。

## 验证

检查真实非空瓦片解码与像素输出、坐标范围、勾选和取消、缩放请求、重复开关、页面切换及刷新；前端执行 eslint --no-ignore 与 verify-sfc。保存运行截图与接入说明，不记录访问令牌或口令。
